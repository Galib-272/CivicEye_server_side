# CivicEye ML workspace

**No datasets have been downloaded and no models have been trained.**

This directory will hold dataset manifests, annotation guidelines, training and evaluation code,
experiment records and model cards (PRD §18–19, Phase 9). Dataset files and model weights are
never committed directly; they will be versioned with DVC.
